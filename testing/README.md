# cookiecutter testing

By: Kyaralp
Mi plantilla personalizada para proyectos de ciencia de datos

## Crear un nuevo proyecto

Para crear un nuevo proyecto a partir de esta plantilla, activa el entorno de Cookiecutter y ejecuta:

```bash
cookiecutter .
```

También puedes utilizar la plantilla directamente desde GitHub:

```bash
cookiecutter https://github.com/klpeluso-droid/cookiecutter-personal.git
```

Sigue las preguntas que aparecen en la terminal para configurar tu proyecto.
